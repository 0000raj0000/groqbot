# COMMAND LINE PERSONAL AI HELP CHAT BOT

## Prerequisites
1. Python
2. UV

## Configuration Steps (WINDOWS)
1. Pull the repo to local computer.
2. Initialize the UV directory by - uv init
3. Install the requirements by - uv add -r requirements.txt
4. Put the GROQ_API_KEY
5. Expose the folder path to the PATH environment variables in WINDOWS.

## Features
1. Complete Incognito Chats
2. Currently not storing the chat history.
3. One way communication.
